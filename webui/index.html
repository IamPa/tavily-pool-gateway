HTTP 接入（Tavily SDK 兼容）

把 SDK 的 base URL 指向本网关即可，无需配置任何 Tavily key（网关自动注入池内 key）。

Python
from tavily import TavilyClient

client = TavilyClient(
    api_key="any",                       # 任意非空即可
    base_url="http://YOUR_GATEWAY:8000/v1",
)
client.search("hello")
cURL
curl -X POST http://YOUR_GATEWAY:8000/v1/search \
  -H "Content-Type: application/json" \
  -d '{"query": "hello world", "max_results": 5}'
MCP 接入（AI 客户端）

支持 MCP 的客户端（Codex / Hermes / Cursor 等）直接添加以下 streamable-http 地址，工具自动注册（tavily_search / tavily_extract 等 7 个）。

MCP URL
http://YOUR_GATEWAY:8000/mcp/

注意：地址末尾的 / 建议保留。当前页面的网关地址即为实际接入地址，把 YOUR_GATEWAY 替换为本网关主机。
